# Reglas de uso de Git

## 1. Ramas principales

El repositorio trabajará con 2 ramas principales:

### `main`
Representa la versión estable del proyecto.  
No se debe trabajar directamente sobre esta rama.

### `develop`
Representa la rama central de desarrollo del Sprint.  
Todo avance aprobado debe integrarse primero en `develop`.

---

## 2. Ramas de trabajo

Cada integrante debe trabajar inicialmente en `develop`, para poder aprobar el proyecto antes de integrarlo en la rama `main`

## 3. Actualización de tareas

Cada integrante es responsable de actualizar sus tareas asignadas en el Kanban, mostrando su flujo real de trabajo
